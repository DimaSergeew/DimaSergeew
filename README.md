- I develop plugins for **Paper**, **Purpur**, **Folia**, and Canvas-based servers.
- I care about focused scope, sensible defaults, performance, and clear documentation.
- I run the technical side of **[PinkyFoxy](https://pinkyfoxy.com)**, an anarchy Minecraft SMP.
- I publish tools that solve a real problem without turning into oversized frameworks.
